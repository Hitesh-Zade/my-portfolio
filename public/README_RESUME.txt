RESUME SETUP INSTRUCTIONS
========================

To enable resume download functionality:

1. Add your resume PDF file to this public directory
2. Name it "resume.pdf" 
3. The resume section will automatically link to this file

Current expected file path: /public/resume.pdf

The resume section component is configured to download this file when users click the "Download Resume" button.

Note: Make sure your resume PDF is optimized for web viewing and doesn't exceed 5MB for better user experience.
